01

趋势折线图

趋势 / 时间序列1120×700 · 通栏改 1880×700
用在：核心指标的月度 / 周度走势 —— 营收、利润、订单量、活跃客户数。回答"涨还是跌、拐点在哪、和去年比如何"。
关键配置：主指标实线 3px 走红 + 极淡红底（#FBE9E9）；对照项（去年同期 / 目标线）灰色虚线 2px。折点用小圆（symbolSize:7），不要每点标数值，只在最高/最低点标。
慎用：类目超过 12 个时改 09 横向条形；只有 2–3 个时点用 06 分组柱更清楚。
02

堆叠面积图

趋势 × 构成1120×700
用在：既要看总量趋势、又要看内部结构变化 —— 三条业务线的收入贡献如何共同推动总营收。
关键配置：最多 3 层（超过 3 层不可读）；层序固定为"大到小"或"战略优先级"；填充用纯色不透明（#CC0000/#006393/#A3A3A3）配 0.75 透明度即可，禁止渐变。
慎用：需要精确读每个系列的数值 → 改 07 堆叠柱；需要看占比演变 → 改 08 百分比堆叠柱。
03

实际 vs 预测（含衔接段）

趋势 / 预测1120×700
用在：年度目标复盘与展望 —— 前 8 个月实际完成、后 4 个月滚动预测，中间用虚线切开。
关键配置：虚线起点与实线终点共享同一个数据点（预测系列在该点也有值），否则会出现断口；预测区底色用 #F5F5F5 竖条（markArea）标出；预测段用 #A3A3A3 虚线，不用红色（红留给已完成事实）。
慎用：预测依据不足时不要画，改 17 帕累托做差距归因。
04

双轴折柱组合

规模 + 速度1120×700
用在："规模"与"速度"要同框 —— 营收（绝对额，柱）与同比增长率（百分比，线）。这是 CFO 汇报里最高频的一张图。
关键配置：柱走蓝灰、线走红（线是结论）；左轴单位"万元"、右轴单位"%"，两侧轴名必须显式标出；增长率用 2px 线 + 数据点标注（每年只有 4–12 个点，可全标）。
慎用：增长率有负值时务必把右轴 min 设为负数并画出 0 轴，否则视觉会误读。
05

阶梯折线图

规则 / 分段1120×700
用在：指标不是连续变化、而是按规则跳档的场景 —— 阶梯定价（量档单价）、佣金费率、折扣阶梯、SLA 分档。
关键配置：step:'end'（当期生效）或 'start'（次期生效）；在每档平台段标出"区间 + 单价"，档与档之间用竖直跳变线；必须标出档位边界值，否则读者读不出规则。
慎用：连续型指标（如营收）误用阶梯图会失真 —— 那是 01 的活。

分组柱状图

环比 / 同比对比1120×700
用在：同一维度下的两个（最多三个）对象逐项对比 —— 今年 vs 去年分季度、我司 vs 竞品分产品、A/B 两个方案分指标。
关键配置：只有 2 个系列（并列柱），当前期走红、对照期走灰；柱宽 barWidth 固定（不用百分比），柱间留白 ≥ 柱宽 1/3；组数 ≥ 8 时改横向（09）。
慎用：3 个以上系列并列会变"彩虹柱"——规范只允许 2 系列走色，其余转 07 / 08。

堆叠柱状图

总量 × 结构1120×700
用在：每月总量 + 内部三条线各贡献多少，两者都要读 —— 月度营收拆分硬件 / 软件 / 服务。
关键配置：层序由下到上 = 由大到小；只给最上面一层标数值（标总量），其余层不标，否则柱子花掉；stack 同名字段必须一致。
慎用：想看某一条线的走势 → 02 堆叠面积；想看占比变化 → 08。

百分比堆叠柱状图

结构占比演变1120×700
用在：总量被抹平后专门看结构漂移 —— 高毛利业务占比是否逐年抬升、渠道结构是否在变。
关键配置：数据必须先换算成百分比（合计 100%）；Y 轴 max:100、formatter:'{value}%'；层内直接标百分比（层够厚时），薄层改到图例侧；层数 ≤ 4。
慎用：总量本身在剧烈波动时，占比会掩盖问题 —— 应与 07 配对使用。

横向条形排名（TOP N）

排名 / 贡献度1120×700
用在：类目多、名称长、要排名 —— 产品线销量 TOP10、渠道贡献排名、问题清单按影响排序。
关键配置：降序排列、第一名走红其余蓝灰阶；条末标数值（position:'right'）；类目名放左轴、前置序号；条高固定、条距恒定，不用背景网格竖线。
慎用：类目 ≤ 6 个且都重要 → 用 06 竖版分组柱，视觉更"正式"。

极坐标柱状图（玉珏）

周期 / 时段分布1120×700
用在：天然带周期循环的指标 —— 24 小时订单分布、一周七天的客流、12 个月的季节性。让人一眼看出"峰谷在哪"。
关键配置：polar + angleAxis（类目）+ radiusAxis（数值）；扇区间留缝 itemStyle.borderWidth:2 白色；峰值扇区单独走红，其余蓝灰；中心可放一句结论（graphic）。
慎用：非周期数据不要用圆环坐标 —— 读者无法比较弧长。

饼图

单一构成1120×700
用在：一个总量的构成，类目少、彼此不可比 —— 营收来源 5 类、费用结构。
关键配置：类目 4–6 个、必须有 1 个明显主导项；主导类目走红、其余用蓝 + 三级灰；直接在外侧标注"名称 + 金额 + 百分比"（label position:'outside' + 引导线）；起始角 startAngle:90 从 12 点顺时针。
慎用：类目 ≥ 7 或占比接近 → 改 09 横向条形（人眼比较角度极差）；需要看趋势 → 08。
12

环形图 + 中心 KPI

构成 + 总量落点1120×700
用在：既要说构成、又要突出一个总量数字 —— 总营收、总成本、总订单量居中亮相。比 11 更有"汇报感"。
关键配置：环宽约占半径 35–45%（radius:['58%','82%']）；中心放 2 行：大数字（48px，红）+ 单位/标签（16px，灰），用 graphic 或 title 实现；环上直接标百分比。
慎用：中心数字与图的构成无对应关系时（如中心放"员工数"、环是"营收构成"）会误导 —— 中心必须是这套构成的总量。
13

南丁格尔玫瑰图

多类目构成1120×700
用在：类目较多（6–10）且想强调量级差异的构成 —— 各渠道客户数、各行业收入贡献。
关键配置：roseType:'radius'（扇形角度等分、半径表数值）；必须按数值排序，否则视觉混乱；外圈标数值；红只给占比最大的一项。
慎用：需要精确比较占比时不要用玫瑰图（面积感知误差大）—— 改 09 或 11。
14

矩形树图 Treemap

层级占比1120×700
用在：类目 10–30 个的面积占比 —— 各产品线 / 各业务板块的收入结构、SKU 销售贡献、成本构成。
关键配置：面积 = 数值；同一族用同一色系深浅阶（蓝系 / 红系 / 灰系各自成组，data 按族排列、sort:'none'，这样同族块会自然聚成一片）；块内标"名称 + 金额"；浅色块上的文字必须换深色（#333333），否则白字看不见；块间留 3px 白缝。
本模板的做法（踩过坑）：ECharts 全展平的 treemap 不会渲染父节点的 upperLabel（该能力只在下钻层级 leafDepth 下生效），所以分组靠"同族同色"表达，组名用底部色块 + 名称 + 金额做图例。另外 levels 里不能同时写 color 数组和 colorSaturation，会抛 e.charAt is not a function 导致整图空白 —— 颜色一律写在节点的 itemStyle.color 上。
慎用：类目 ≤ 6 个时用饼图 / 条形更直观；需要看趋势变化 → 08。

旭日图 Sunburst

二级下钻构成1120×700
用在：明确的两层归属关系且要同时读内外圈 —— 区域 → 城市、事业部 → 产线、渠道 → 门店。
关键配置：内圈 = 一级（总额）、外圈 = 二级；内外圈同族同色相（内深外浅），一眼看出归属；外圈标占比、内圈标名称 + 合计。
慎用：层数 ≥ 3 时外圈会细如发丝 —— 经营分析只用 2 层，第 3 层改用 14 或下钻页。
D · 拆解与归因 从哪儿来的差异、谁的责任 —— 回答"为什么没达成"

瀑布图（增减归因）

差异拆解 / 归因1120×700 · 建议通栏
用在：从起点走到终点，中间的每一项各贡献多少 —— 预算 → 实际的差异归因、上季度 → 本季度的利润变化、客户数净增的加减拆解。经营分析最有说服力的一张图。
关键配置：用两个 series 堆叠实现：底层透明柱（itemStyle.opacity:0）做托举、上层可见柱表增减；首尾两根是"总值"柱（红），中间是增减柱（增 = 蓝 #006393、减 = 灰 #A3A3A3）；增减柱之间画 1px 虚线连接（markLine 或自定义）；每根柱直接标数值 + 正负号。
慎用：增减项超过 7 个时归并成"其他"；终点必须等于起点 + 各项代数和，算不平就不要画。
17

帕累托图（ABC 分析）

80/20 关键少数1120×700 · 建议通栏
用在：找关键少数 —— 哪些 20% 的产品贡献了 80% 的收入、哪些客户是利润主力、缺陷类型按影响排序。
关键配置：柱 = 各项金额降序（蓝灰阶），折线 = 累计占比（红，右轴 0–100%）；必须画 80% 水平参考虚线，并标出与折线交点对应的类目数（如"前 3 项占 80%"）；右轴 max:100, formatter:'{value}%'。
慎用：类目 ≥ 15 时横轴挤 → 只保留前 10 + "其他"；折线务必从 0 起、末点收在 100%。
18

双向贡献条形图

正负贡献 / 增量来源1120×700
用在：各单元的增量贡献有正有负 —— 区域净增、品类同比增减、分公司缺口与超额。
关键配置：类目轴放中间、值为 0 的竖直基准线；正向条向红/蓝（增长）、负向条向灰（拖累）；条末标数值 + 正负号；按数值大小排序（正的在上、负的在下）。
慎用：全部同号时不要用双向图（左半边全空）—— 改 09 横向条形。
19

桑基流向图

流向 / 资源分配1120×700 · 建议通栏
用在：资源 / 客户 / 资金在多个环节之间流动 —— 预算分配到各渠道再落到各业务、客户从获客渠道流向留存/流失、订单从品类流向区域。
关键配置：3 层最多（源 → 中转 → 结果）；节点按数值降序排列、线宽 = 流量；节点用红（结论层）/蓝（中间层）/灰阶；线用 0.35 透明度，交叉线不得遮挡标签。
慎用：节点 ≥ 15 时会糊成一团 —— 归并小节点为"其他"；单向线性关系用 12 Chevron 更清楚。

散点图 + 回归趋势线

相关性 / 投入产出1120×700
用在：验证两个指标是否"同向走" —— 广告投入 vs 销售产出、促销力度 vs 客单价、单价 vs 销量。
关键配置：一轴一个指标、两轴都要标单位；散点用灰色小圆（symbolSize:10、透明度 0.6）；趋势线单独一个 line series（红 2px 虚线）；务必标出 R² 或相关系数，并说明"相关不等于因果"。
慎用：样本 < 8 个时不要画趋势线；有异常点要单独标出（markPoint）。

气泡图（三变量）

三变量定位1120×700
用在：一张图看三个变量 —— X 轴增长率、Y 轴毛利率、气泡大小营收规模。"哪些业务又大又快又赚"一目了然。
关键配置：气泡 symbolSize 按数值线性映射（半径映射，不是面积，需在注释说明）；每个气泡直接标名称；用四分位参考线（markLine 两条中线）切成四个象限，象限注释放四角。
慎用：气泡 ≥ 12 个必然重叠 —— 控制在 6–10 个；气泡之间大小差异不要超过 5 倍。

箱线图（分布 / 波动）

分布 / 稳定性1120×700
用在：看波动与稳定性，而不是看平均值 —— 各区域月度达成率的离散度、各门店日均销量分布、指标的一致性对比。
关键配置：一个类目一箱 = 五数概括（最小 / Q1 / 中位 / Q3 / 最大）；中位线走红（这是"典型水平"）；异常点用灰点单独画（type:'scatter'）；轴标签注明单位与周期。
慎用：样本 < 8 个时箱线没有统计意义 → 直接画个体点（散点/条形）。汇报对象没听过箱线图时，务必在图注里解释五条线的含义。

热力矩阵

二维交叉 / 密度1120×700
用在：两个维度交叉后看密度或水平 —— 品类 × 星期的销量强度、区域 × 月份的达成率、时段 × 门店的客流。
关键配置：色阶用同一色相 4–5 阶（浅红 → 深红，或浅蓝 → 深蓝），visualMap 放右侧竖向、显式标出数值范围；格内标数值（格够大时）；格间用 2px 白缝。
慎用：禁止用彩虹色阶（红黄绿蓝），那是 Heatmap 最典型的错误；两个维度的类目数都 ≥ 15 时格子会读不清。

转化漏斗图

转化率 / 环节流失1120×700
用在：有明确先后顺序的环节逐级流失 —— 曝光 → 访问 → 加购 → 下单 → 支付；线索 → 商机 → 报价 → 成交。
关键配置：sort:'descending'；每层标"绝对值 + 本级转化率 + 累计转化率"（三者缺一，读者会算错）；层间距 gap:4；瓶颈环节单独走红（转化率最低那一跳）。
慎用：环节之间没有先后关系时不要用漏斗（例如"构成"类）—— 那是 11 的活。漏斗的层数控制在 4–6 层。

仪表盘（达成率）

KPI 达成1120×700 · 常与 KPI 卡并置
用在：单个核心 KPI 的目标达成进度 —— 年度营收完成 108%、生产计划达成 96%、客户满意度 4.6/5。
关键配置：半环（startAngle:180, endAngle:0）；100% 位置必须有显式刻度标记，否则看不出"超了还是欠了"；axisLine.lineStyle.color 用分段色：未达成段灰、达成段红；指针细窄（width:6）；中心数字 48px。
慎用：一页最多一个仪表盘；多个 KPI 用 26 进度条组或 17 KPI 大数字条。仪表盘只表"一个数对一个目标"，不要塞多个指针。

雷达图（多维对比）

多维能力 / 综合评分1120×700
用在：4–8 个维度的综合画像与对比 —— 六个能力维度上"我司 vs 竞品"、"本季度 vs 上季度"、"三家分公司"。

关系网络图（Graph）

主体关系 / 结构1120×700
用在：经营要素之间的连接关系 —— 业务板块之间的收入依赖、客户与产品的交叉覆盖、供应链上下游关系、组织与指标的挂接。
关键配置：layout:'force' + repulsion 拉开距离；节点大小 = 权重、核心节点走红；连线粗细 = 关系强度、透明度 0.35；节点标签必须全部可见（label.show:true），必要时只标重点节点。
慎用：节点 ≥ 20 时成"毛线球"—— 只画核心节点 + 一层关联；层级关系用 14 树图 / 15 旭日图更准确，力导向图只适合表达"网状、无层级"的关系。
使用口诀 选图只问三句话
第一句 —— 我有几个变量？
1 个（一个指标随时间走）→ 01 / 02 / 03 / 05； 2 个（规模 + 速度）→ 04； 1 个类目 + 1 个数值 → 06–13； 2 个数值 → 20； 3 个数值 → 21； 2 个维度交叉 → 23； 4–8 个维度 → 27。

第二句 —— 我要读者记住什么？
"在涨" → 01； "结构在变" → 02 / 08； "谁第一" → 09； "大头是谁" → 11 / 12； "为什么差" → 16； "关键少数" → 17； "卡在哪" → 24； "到没到" → 25 / 26。

第三句 —— 这个选择有什么风险？
读者能否在 5 秒内从这张图里读出一个结论？读不出 → 换图或拆成两页。图再漂亮，读不出结论就是装饰。
