思维是一条从「问题定义」到「执行闭环」的链条

01 · FRAMEWORK

思考能力 = 定义问题、分析问题、解决问题的能力核心链条：问题定义 → 确定目标 → 分解与关联 → 排序与组合 → 决策闭环

思考的本质是分析与决策，「维」的本质是结构化

02 · THINKING

思考 = 自我驱动的独立意识下的思维活动；只要主动想，就是思考经验积累 × 客观事物 × 主观直觉，三者在思维过程中缺一不可

三要素缺一不可

历史经验积累 · 客观事物本身 · 主观想法与直觉
缺了经验，思考脱离实际；只凭经验，思考沦为空谈

消极思考也是思考

只要由独立意识驱动，都是思考行为
而且很可能由消极思考转化为积极思考

常识的获取方式才是关键

被动接受是学习行为，思考成分很少
亲身实践总结出的结论，才是真正的思考

破题：把「怎么办」的问题翻译成「要什么」的目标

03 · PROBLEM

不破不立：思考的第一步是确定目标，而确定目标的重点是破题从「对问题表象的思考」转化为「对目标本身的定义」

好目标必须同时标注时间性与空间性

04 · OBJECTIVE

只有同时具备时间性与空间性的目标，才是可执行、可分解的完整目标时间性 = SMART 的 T；空间性 ≈ S + M

时间性决定战略性与前瞻性

当年利润最大化与 3 年利润最大化，决策要素完全不同
提醒目标的时间性，就是在保持思维的战略性

空间性定义范围与程度

达到什么程度、覆盖什么范围，必须可量化
空间 + 时间，才是一个完整的目标

先形成单一的终极目标

一开始就进入多目标平衡，思考必然陷入僵局
终极目标是后续分解与决策的起点

先定终极目标，再谈影响因素与平衡

05 · GOAL

目标是基础，不是用来平衡的；需要平衡的只有影响因素与制约因素两条路径：问题 → 期望 → 目标；子目标 → 终极目标

目标分解的四层逻辑树：从子目标到关键控制变量

06 · DECOMPOSE

分解之根本：让后续的计划、行动与呈现全部围绕目标展开四个层次：终极目标 → 子目标 → 关键成功要素 → 关键控制变量

分解即形成逻辑树

MECE：完全穷尽、相互独立，同层同类别
结构化 = 层次性 + 粒度同一性 + 分类同属性

用 SMART 区分层级

符合 SMART 的是子目标
不符合的，就是关键成功要素 CSF

树模型统一了所有工具

逻辑树、问题树、决策树、思维导图、鱼骨图
归根到底都是树模型的应用

分解的三条纪律：不混层、不混抽象度、同层同粒度

07 · PRINCIPLE

分解的结构化 = 层次性 + 粒度同一性 + 分类同属性三个最常见的错误：静态动态混层、抽象具体混层、同层粒度不一致

自顶向下走不通时，用流程分析 + 头脑风暴由下向上建树

08 · PROCESS

有经验靠「假设—验证」，全新领域靠「流程分析 + 头脑风暴」流程分析保证覆盖不遗漏，再由下向上分组归纳成问题分解树

文章来源：何明璐《我是如此思考的-思维整体框架和逻辑》· 公众号「人月聊IT」09 / 12

排序给分值，组合给边界：矩阵分析找到要素的分组

09 · PRIORITIZE

优先级是多个属性的综合衡量，而不是单一指标排序组合分析要的不是排序分值，而是分组边界

单要素排序简单但不科学

按销售额、利润、客户数排序，谁都会做
但它回答不了「应该先做哪一件」

优先级 = 多属性的综合

购房看价格 / 学位 / 交通 / 环境
性能优化看提升幅度 / 难度 / 成本

排序之后必须组合

一个要素变好，另一个往往变差
用矩阵找出分组边界，而不是排序分值

决策的价值不在选择，而在多目标平衡与执行闭环

10 · DECISION

决策的目的是行动，执行的目的是解决问题决策的难点在多目标平衡，价值在执行与反馈闭环
